# lightgbm
## Hướng dẫn làm nhiệm vụ 1
```bash
Bước 1: clone dự án đã cấu hình sẵn về máy tính cá nhân
Bước 2: tạo môi trường ảo
    - Tham khảo https://github.com/thang170725/Notes.git để xem các tạo môi trường ảo trên windows
        + Stack > Languages > Python > Base.md > bấm "Tạo môi trường ảo & activate" ở đầu trang
Bước 3: sau khi tạo môi trường ảo và activate thành công thì chạy lệnh
    - pip install -r requirements.txt (để cài đặt các thư viện)
Bước 4: Truy cập vào docs/task.md để nhận nhiệm vụ và làm theo
Bước 5: Viết code
    - Lưu ý trước khi viết code phải pull về
```
